# 🎮 GameDrop PRD

## 1. 프로젝트 소개

### 프로젝트 이름
**GameDrop**

### 프로젝트 설명
GameDrop은 사람들이 인기 게임을 찾고, 출시 예정 게임 날짜를 확인하고, 마음에 드는 게임을 저장할 수 있는 게임 추천 웹사이트입니다.

쉽게 말하면:

> “Steam 느낌의 UI를 가진 게임 추천 플랫폼”

---

# 2. 프로젝트 목표

- 실제 게임 플랫폼 같은 사이트 만들기
- 게임 정보를 API로 가져오기
- React 기반 웹사이트 제작
- 위시리스트 기능 구현
- 출시일 캘린더 구현
- 반응형 웹사이트 제작
  - 모바일
  - 태블릿
  - 데스크탑 지원

---

# 3. 주요 사용자

- Steam 자주 사용하는 사람
- 신작 게임 좋아하는 사람
- 게임 추천 받고 싶은 사람
- 출시 예정 게임 확인하고 싶은 사람

---

# 4. 주요 기능 (MVP)

## 4-1. 메인 페이지

### 기능
- 인기 게임 목록 보여주기
- 게임 이미지 표시
- 메타크리틱 점수 표시
- 게임 장르 표시
- 위시리스트 저장 버튼 제공

### Hover 효과
게임 카드에 마우스를 올리면:

- 게임 제목
- 점수
- 장르
- 저장 버튼

이 나타납니다.

### UI 특징
- 카드 확대 애니메이션
- 이미지 밝기 변화
- 부드러운 transition 효과
- 반응형 Grid 레이아웃

---

## 4-2. 출시 달력 페이지

### 기능
- 게임 출시 날짜를 달력 형태로 표시
- 날짜 클릭 시 출시 예정 게임 목록 출력

### 예시

```text
5월 10일 클릭
→ GTA6 출시 예정
→ Hollow Knight 출시 예정
